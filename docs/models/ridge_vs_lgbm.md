# Head to head: ridge vs lgbm

Generated by `finmgr compare-models ridge lgbm --as-of 2026-11-12` from the local store, data as of 2026-11-12. The code is
`finmgr/models/headtohead.py` (the runs and the checks) and
`finmgr/report/headtohead.py` (this page). Rerun the command after any change to
either model, the features, the engine, costs or data, and commit the regenerated page.

## Verdict

* **ridge**: does not beat the bar: Sharpe 0.89 ≤ 1.08.
* **lgbm**: does not beat the bar: Sharpe 0.77 ≤ 1.08.
* **lgbm against ridge**: lgbm and ridge cannot be told apart. Sharpe difference -0.12, paired 95% interval [-0.39, +0.17]; lgbm has the higher mean IC in 25 of 64 folds.

## Is the comparison fair?

All the models were trained and backtested in one process, on one `Dataset`
(one feature matrix, one label) and one set of backtest inputs and costs. The
checks below compare the finished runs field by field: the command refuses to
write this page if any of them differ.

| Check | Result | What was compared |
| --- | --- | --- |

| split settings | ✅ same | test 63, min train 200, expanding, embargo 21 |
| fold boundaries | ✅ same | 65 folds, train and test dates identical in every one |
| rows fitted per fold | ✅ same | 14,091,288 training rows over all folds |
